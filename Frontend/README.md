# 🩸 Blood Bank Frontend

This directory contains the React + Vite frontend for the Blood Bank project. 

For full setup instructions, backend configuration, and project details, please refer to the main **[README.md](../README.md)** file in the root directory.

### Quick Start
To run the frontend locally:
```bash
npm install
npm run dev
```
Make sure you have a `.env` file initialized with `VITE_API_BASE_URL` properly pointing to your backend!
